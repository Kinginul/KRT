## Install

### Copy script siap pakai

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Kinginul/emotemotawaw/main/budi.lua"))()
```

### Langkah cepat

1. Buka executor Roblox yang mendukung Lua.
2. Paste script di atas.
3. Jalankan script di game yang sedang dimainkan.
4. Tunggu UI KRT muncul.
5. Gunakan tab Main, Visual, Player, atau Settings.

## Fitur Utama

### 1. Sprint System

- Mode Hold: sprint aktif saat tombol ditekan.
- Mode Toggle: sprint aktif atau nonaktif dengan satu klik.
- FOV diperkecil dan diperbesar secara halus agar terasa natural.

### 2. Fly Mode

- Dapat diaktifkan dengan tombol atau shortcut F.
- Gerakan meluncur lebih smooth menggunakan BodyVelocity dan BodyGyro.
- Dapat direset kapan saja dari tab Visual.

### 3. Teleport Player

- Menampilkan daftar player lain dalam panel Player.
- Setiap row player memiliki tombol TP.
- Setelah teleport, ada efek ring kecil yang muncul.

### 4. Auto Refresh List

- Player list otomatis update saat ada yang masuk atau keluar.
- User tidak perlu refresh manual.

### 5. Premium HUD

- Desain dark premium dengan layout yang bersih.
- Tab yang mudah dibaca.
- Smooth saat drag, hover, dan transisi panel.

### 6. Troll Fun

Script ini memiliki beberapa prank lucu yang siap dipakai:

- Troll Spin
- Laugh Burst
- Screen Shake
- Fake Ban
- Chaos Spin
- Noob Float

Semua fitur ini dibuat untuk efek hiburan dan prank ringan agar lebih seru saat digunakan.
